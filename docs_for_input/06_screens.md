# 06 画面 / UI 要件

現デモの画面構成を踏襲しつつ、認証・相場実データ化に必要な画面を追加する。

## 画面一覧

| 画面 | 状態 | 主な要素 |
|---|---|---|
| ① マイコレクション一覧 | デモ実装済み | サマリーカード4種、検索/フィルタ/ソート、作品カードのグリッド |
| ② 作品 登録/編集モーダル | デモ実装済み | 全項目フォーム、状態フラグ、写真、削除 |
| ③ マーケット一覧 | デモ実装済み（ダミー） | 出品/相場カード、スパークライン、トレンド、ソート |
| ④ マーケット詳細モーダル | デモ実装済み（ダミー） | 12ヶ月チャート、最安/最高/変動、ウォッチ追加 |
| ⑤ ログイン/新規登録 | **新規(MVP)** | OAuth/メール、利用規約同意 |
| ⑥ アカウント設定 | **新規(MVP)** | プロフィール、データエクスポート/インポート、退会 |
| ⑦ 相場アラート設定 | 新規(フェーズ3) | しきい値、通知先 |
| ⑧ 記事/プレミア検出 | 新規(フェーズ3) | SEO集客コンテンツ |

## 画面遷移（MVP）

```
[未ログイン] ─> ⑤ログイン ─> ①マイコレクション ⇄ ③マーケット
                                  │  ├─ ②登録/編集モーダル
                                  │  └─ ⑥アカウント設定
                                  └─ ④マーケット詳細モーダル
```

- ヘッダのタブ「マイコレクション / マーケット」で①③を切替（デモのswitchView踏襲）。
- 未ログイン時は閲覧範囲を限定（マーケットの一部のみ公開 等は将来検討）。

## UI要件

- **レスポンシブ**：スマホ/PC両対応（デモのグリッドは `auto-fill/minmax` で対応済み）。
- **ダークテーマ**：デモの配色（`--bg:#0f1115` 等）を継承。ブランドカラー `--accent:#e0245e`。
- **損益の色分け**：含み益=緑(`--plus`)、含み損=赤(`--minus`)。デモ踏襲。
- **状態バッジ**：初版（hotバッジ）・帯・特装/サインをカード上に表示。
- **空状態**：未登録時のガイド表示（デモ実装済み）。
- **相場の鮮度表示**：相場の `market_source`（手入力/自動/推定）と更新日を明示（実データ化後、信頼性のため必須）。

## 新規画面の要件メモ

### ⑤ ログイン/新規登録
- OAuth（Google）優先 ＋ メール。利用規約・プライバシーポリシー同意必須（NFR-4）。
- 既存デモユーザー向けに「JSONを取り込んで始める」導線（FR-C3）。

### ⑥ アカウント設定
- データのエクスポート（JSON、FR-A7）/ インポート。
- 退会＝データ削除（FR-C4、NFR-4）。

## 既存デモからの主な変更点

- 「現在相場」入力欄：MVPは手入力のまま。フェーズ2で「自動取得値＋手動上書き」のUIへ。
- 「ウォッチに追加（デモ）」のダミー → 実機能化（フェーズ3）。
- 画像：ローカルdataURL → アップロードしてサーバ保存。
