## 用語

- **マイカ** … DMMマイカ（旧Mycalinks）。トレカの「管理＋相場＋EC」統合アプリ。本プロダクトはこれの漫画版を志向。
- **相場** … 中古市場での実勢価格。本プロダクトの中核価値の一つ。
- **含み損益** … 取得価格と現在相場の差。資産管理機能の中核指標。
