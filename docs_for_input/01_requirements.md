# 01 要件（機能要件 / 非機能要件）

優先度: **P0**=MVP必須 / **P1**=MVP後すぐ / **P2**=将来。

## 機能要件（FR）

### A. コレクション管理（資産管理）

| ID | 要件 | 優先 | 備考 |
|---|---|---|---|
| FR-A1 | 作品を登録（タイトル/著者/出版社/巻数/発行年/コンディション/所有数/取得価格/現在相場/購入日/購入店/保管場所/状態フラグ/メモ/写真） | P0 | デモ実装済み。項目は `03_data_model.md` |
| FR-A2 | 作品の編集・削除 | P0 | デモ実装済み |
| FR-A3 | 状態フラグ：初版・帯付き・特装/サイン本 | P0 | 価格に効く重要属性 |
| FR-A4 | 写真の添付（自動縮小して保存） | P0 | デモは600px/JPEG0.8で縮小 |
| FR-A5 | サマリー表示：登録点数・総取得額・現在評価額・含み損益 | P0 | 資産管理の中核 |
| FR-A6 | 検索（タイトル/著者/出版社）・フィルタ（初版/帯/特装/含み益/含み損）・ソート | P0 | デモ実装済み |
| FR-A7 | データのバックアップ書出し / 読込（JSON） | P0 | サーバ化後もエクスポートは残す |
| FR-A8 | 現在相場の**自動反映**（手入力でなく相場データと自動連携） | P1 | `04_market_data.md` に依存 |
| FR-A9 | コレクション全体の資産推移グラフ（時系列） | P1 | 相場履歴の蓄積が前提 |
| FR-A10 | 複数コレクション/タグ分類、CSVインポート | P2 | |

### B. 相場（マーケット）

| ID | 要件 | 優先 | 備考 |
|---|---|---|---|
| FR-B1 | 作品ごとの相場表示（現在価格・期間最安/最高） | P0 | デモはダミー。実データ化が本番要件 |
| FR-B2 | 価格推移チャート（12ヶ月など） | P0 | デモ実装済み（描画部分） |
| FR-B3 | コンディション別（初版/帯/特装）の相場分離 | P1 | hobipediaの差別化点を踏襲 |
| FR-B4 | 相場ランキング・トレンド（値上がり率順） | P1 | |
| FR-B5 | 価格アラート（しきい値到達で通知） | P1 | hobipediaにあり。メール/プッシュ |
| FR-B6 | ウォッチリスト | P1 | デモはダミーボタンのみ |
| FR-B7 | 週刊誌バックナンバー相場 | P2 | hobipediaが対応。差別化拡張 |

### C. アカウント / 基盤

| ID | 要件 | 優先 | 備考 |
|---|---|---|---|
| FR-C1 | ユーザー登録・ログイン（メール or OAuth） | P0 | 複数ユーザー化・データ永続化に必須 |
| FR-C2 | クラウドにコレクションを保存（端末間同期） | P0 | localStorage脱却 |
| FR-C3 | デモのlocalStorageデータをアカウントへ移行（JSON取込） | P1 | 既存FR-A7を流用 |
| FR-C4 | 退会・データ削除（個人情報保護対応） | P0 | 法令対応 |

## 非機能要件（NFR）

| ID | 種別 | 要件 |
|---|---|---|
| NFR-1 | 性能 | コレクション1,000点でも一覧表示・検索が体感1秒以内 |
| NFR-2 | 可用性 | 個人/小規模運用想定。月次稼働99%目標、計画停止は告知 |
| NFR-3 | セキュリティ | 通信TLS、パスワードはハッシュ保存、画像/個人データのアクセス制御 |
| NFR-4 | プライバシー | コレクションは原則非公開（本人のみ）。公開機能を作る場合は明示オプトイン |
| NFR-5 | データ保全 | DB定期バックアップ、ユーザーによるエクスポートを常時提供 |
| NFR-6 | レスポンシブ | スマホ/PCブラウザ両対応（デモはレスポンシブ済み） |
| NFR-7 | 法令順守 | 相場データの取得・表示が各サービスのToS/著作権に抵触しないこと（`04`/`08`） |
| NFR-8 | 保守性 | 単一HTMLからコンポーネント構成へ。相場取得はバッチ/ジョブで分離 |
| NFR-9 | コスト | 初期は低コスト構成（無料〜低額枠）で運用可能なこと |

## 受け入れ観点（MVP完了の定義）

- 新規ユーザーが登録 → ログイン → 作品を10点登録 → 含み損益サマリーが正しく表示 → 別端末でログインしても同じデータが見える。
- 少なくとも一部の作品で**実データに基づく相場**が表示される（ダミーでない）。
- データのエクスポート/インポートが往復で破綻しない。
