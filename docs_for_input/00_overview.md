# 00 プロダクト概要

## 1. ビジョン

プレミア漫画（初版・帯付き・特装・サイン本などの希少コミック）の**コレクション管理**と**相場確認**を一体で提供するWebサービス。
コレクターが「自分の蔵書が今いくらの価値か」「どれが値上がりしているか」を一目で把握でき、資産としての漫画コレクションを管理できる状態を目指す。

DMMマイカがトレーディングカードで実現している「**管理 ＋ 相場 ＋ 取引**」のうち、まず**管理 ＋ 相場**の2レイヤーを漫画領域で確立する。

## 2. 解決する課題

- コレクターは自分の蔵書の**現在価値を把握できていない**（バラバラの記憶・スプレッドシート管理）。
- 初版・帯付きなど**コンディション差が価格に大きく効く**のに、既存の買取相場サイトは状態を均してしまう。
- 「いつ売るか」の判断材料（値上がりトレンド・相場アラート）がない。

## 3. 競合・参照サービス

| サービス | 性格 | 本プロダクトとの差 |
|---|---|---|
| DMMマイカ | トレカの管理＋相場＋EC | 対象がトレカ。漫画は手薄 |
| comic.hobipedia.jp（初版コミック相場β） | 初版漫画・週刊誌の**相場特化**（メルカリsoldベース） | 個人の**コレクション管理（資産・含み損益）が無い** |
| まんだらけ / 駿河屋 | 高額漫画の買取・委託、相場DB | 自分の蔵書を**手元で管理する道具ではない** |
| メルカリ / ヤフオク | 実取引の場 | 相場の集約・資産管理ビューが無い |

**本プロダクトの立ち位置**＝「相場（hobipedia的）」×「資産管理（マイカ的）」を**個人の蔵書に紐づけて統合**する点が差別化の核。

## 4. 現状デモの位置づけ（[../index.html](../index.html)）

単一HTMLファイルのSPA。すでに2軸を実装済み：

- **マイコレクション**：localStorage保存、作品のCRUD、画像アップロード（自動縮小）、JSONバックアップ/読込、サマリー（登録点数/総取得額/現在評価額/含み損益）、検索・フィルタ・ソート。
- **マーケット**：価格推移チャート、トレンド/価格ソート、詳細モーダル（12ヶ月チャート、ウォッチ）。**※相場データは現状ダミー（クライアントで擬似生成）**。

→ UIとデータモデルの叩き台として有効。本番化で必要なのは主に **(a) サーバ/DB化、(b) 相場データの実データ化、(c) 認証・複数ユーザー対応**。

## 5. ターゲットユーザー

- **主**：漫画コレクター（初版・希少本を複数所有し、資産価値を気にする層）。
- **副**：せどり/転売目的で相場をウォッチする層（hobipediaの主要ユーザー層と重なる）。
- 将来：売買したいライト層（マーケットプレイス化フェーズ）。

## 6. スコープ外（現フェーズ）

- ユーザー間の売買・決済・委託（将来フェーズ。`07_business.md` 参照）。
- 真贋鑑定そのものの提供（CGC等の外部鑑定との連携は将来検討）。
- 漫画本文の閲覧・電子書籍機能（一切扱わない＝著作権リスク回避、`08_risks.md`）。
